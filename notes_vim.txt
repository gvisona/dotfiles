- Display location in file: <Ctrl g>

- Move to previous instance of word under cursor: <#>
- Move to next instance of word under cursor: <*>

- Reselect last highlighted text: <gv>

- Activate insert mode from visual mode: <I> 
- Activate append mode from visual mode: <A> 

- Toggle case of character under cursor: <~>
- Toggle case of selection: <g~ (selection)>

- Open url under cursor: <gx>

- Scroll editor up and down with <Ctrl y> and <Ctrl e>
- Center current line in editor <zz>. Put the cursor line at top of scroll <zt> and at bottom with <zb>

- In visual block mode, <o> jumps to the other corner of the block, while <O> to the other side

- If searching with telescope, <Ctrl q> will add the files in the list to a quicklist. Afterwards
it is possible to run commands on all those file. e.g. `:cdo s/oldString/newString/gc will find and 
replace with confirmation within all those files.

- The mini ai plugin enhances the selection around (`a`) and in (`i`) textobjects. The use of `n` and `l`
can also adapt to regions outside the cursor (e.g. `vin(` visually selects the content of the next round 
brackets.)
Useful selectors are also `t` for tag, `b` for brackets `B` for curly braces, `q` for quote.

- The mini surround plugin uses the keymaps `sa` for surround add, `sd` for surround delete, and `sr`
for surround replace. These first two characters have to essentially be pressed together.
surround also allows the use of `b` and `q` like mini ai.
sa+selector+f is particularly useful to enclose a part of the text in a function call.
also allows the use of `n` and `l` like ai for external referencing.
Repeating a selector with repleacement introduces padding: e.g. (text) with `srn((` -> ( text )


- FAMILIARIZE WITH mini ai, mini surround and mini operator !!!!!

- It is possible to show the source of diagnostic messages by hovering with the cursor and pressing <Ctrl w> and <d>
This also shows the source of the message if configured.


Completion can be done for:

1. Whole lines						|i_CTRL-X_CTRL-L|
2. keywords in the current file				|i_CTRL-X_CTRL-N|
3. keywords in 'dictionary'				|i_CTRL-X_CTRL-K|
4. keywords in 'thesaurus', thesaurus-style		|i_CTRL-X_CTRL-T|
5. keywords in the current and included files		|i_CTRL-X_CTRL-I|
6. tags							|i_CTRL-X_CTRL-]|
7. file names						|i_CTRL-X_CTRL-F|
8. definitions or macros				|i_CTRL-X_CTRL-D|
9. Vim command-line					|i_CTRL-X_CTRL-V|
10. User defined completion				|i_CTRL-X_CTRL-U|
11. omni completion					|i_CTRL-X_CTRL-O|
12. Spelling suggestions				|i_CTRL-X_s|
13. keywords in 'complete'				|i_CTRL-N| |i_CTRL-P|

Additionally, |i_CTRL-X_CTRL-Z| stops completion without changing the text.

All these, except CTRL-N and CTRL-P, are done in CTRL-X mode.  This is a
sub-mode of Insert and Replace modes.  You enter CTRL-X mode by typing CTRL-X
and one of the CTRL-X commands.  You exit CTRL-X mode by typing a key that is
not a valid CTRL-X mode command.  Valid keys are the CTRL-X command itself,
CTRL-N (next), and CTRL-P (previous).


- You can check the keymaps set in vim, use ':nmap' in normal mode. This gives all the mappings for
normal mode. You can also filter, for example using ':nmap <leader>'.
- Using ':verbose nmap <leader>' shows where the keymaps were last set, while ':Telescope keymaps'
brings up the list in a telescope window.
